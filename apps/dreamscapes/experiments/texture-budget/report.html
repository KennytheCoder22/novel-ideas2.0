Plain / Stuffed non-destructive texture experiment

17 October 2026. Original assets, production mappings, Carousel transforms, crops, 80% render resolution, materials and runtime remain unchanged. No deployment or adoption.

Smallest acceptable settings tested

JPEG quality 75, 4:4:4 chroma, optimized encoding. Keep 2K textures and existing geometry for the 16 ordinary mounts plus Horse. Horse remains approximately 77k triangles; no 22k reduction was tested. Polar Bear and Zebra use 1K textures and approximately 75k triangles. Rocket uses 2K textures and 67,999 triangles. Q85 and Q75 texture-only alternatives are retained.

Normal-distance comparisons at 1920×1080, DPR 1, unchanged scene framing show no obvious meaningful loss in fur, stripes, saddle edges, antlers or silhouettes. Eight phase captures were generated per trial; cardinal phases were reviewed side by side at native screen pixel size. This is an assessment at the current Carousel distance, not a guarantee for close zoom, all displays, or a claim that Q75 is the theoretical minimum. Only Polar Bear/Zebra were downsampled.

Reproduce

From this experiment directory, with Python/Pillow and Node installed:

python -m pip install -r requirements.txt
npm install --prefix tools
python recompress.py
node simplify.mjs
python build-budget.py
node verify-registration.mjs
python serve.py --port 4211

For browser measurements, install Playwright separately or set PLAYWRIGHT_MODULE to its installed module path. BROWSER_EXE can select Edge/Chrome. Run compare.cjs (original/Q85/Q75), then with TRIAL_PROFILES=budget run compare.cjs again; run measure-motion.cjs for normal animation. Run make-review.py and make-report.py to regenerate outputs. check-results.py verifies originals.

Generated copies, intermediate meshes and screenshots are local experiment outputs, reproducible from the tracked source GLBs. Nothing under this experiment directory is included by the Dreamscapes public-only build. No production replacement has been made.
