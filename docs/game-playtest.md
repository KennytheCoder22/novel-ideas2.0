# Game playtest evaluation

`npm run test:game-playtest` runs deterministic metric, privacy, replay, and fixture-gate regressions.

For developer screenshots, run `npm run capture:game-playtest`. It writes and verifies 66 ignored PNG captures (22 representative game states at desktop, tablet, and phone) in `artifacts/game-playtest-screenshots/`. The command starts Expo web with `EXPO_PUBLIC_GAME_PLAYTEST_FIXTURES=1` and uses Chrome or Edge. Set `PLAYTEST_BROWSER` to an executable when it cannot be discovered; set `PLAYTEST_BASE_URL` to capture an already-running development server (which must also have the public fixture environment flag). Fixtures redirect in production and are not linked from normal navigation. Before every capture, Chrome/Edge dumps the DOM and the script requires that state's fixture sentinel, refusing to capture a homepage or another non-fixture page.

**These captures are not frame-exact recordings of the real game routes.** `app/admin/game-playtest-fixtures.tsx` renders deterministic, bespoke presentational layouts for each of the 22 states, reusing real production content and contracts (catalog titles/creators, encounter/customer/work data, scenario copy, catalyst copy) so the captures are grounded in genuine game data — but it does not mount `/media-mania`, `/games/last-bookshop`, `/games/unwritten-map`, or `/games/alchemists-cascade` themselves, so exact layout and interaction chrome will differ from live play. Treat these PNGs as illustrative production-content fixtures for reviewing metric/replay coverage, not as gameplay screen recordings.
