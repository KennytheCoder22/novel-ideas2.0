# Melanie's Game content authoring

Melanie's Game ships a versioned library of exactly 64 fictional concepts for each supported age band. The core catalog lives in `melaniesGame.ts`; additional authored entries live in `melaniesGameExpandedConcepts.ts`.

Each concept needs:

- a globally unique, age-prefixed ID, title, and one-sentence synopsis;
- the correct age band and a two-color hexadecimal palette;
- all nine bounded taste dimensions (`-2` through `2`);
- authored genre, tone, theme, character-dynamic, and setting values;
- an explicit semantic fingerprint covering premise family, central activity, setting class, protagonist role, narrative engine, relationship shape, speculative device, stakes, social focus, and at least two cover motifs;
- a premise that is materially distinct from every other concept.

Concept covers are local vector compositions generated by `melaniesGameCoverArt.ts`. Every concept receives a versioned asset ID, premise-derived primary and secondary subjects, a composition, a frame, and unique scene geometry. The UI creates only the covers in the active six-item round, so expanding the catalog does not eagerly decode hundreds of image files.

After adding or editing concepts, run:

```sh
npm run audit:melanies-game-content
npm run test:melanies-game
```

The integrity audit combines token and synopsis-shingle similarity with semantic-fingerprint overlap, and reports the exact concept pair and shared signals when a likely duplicate is found. It also fails on incorrect age-band counts, cross-age leakage, malformed metadata, weak taxonomy coverage, dominant templates, duplicate cover IDs or composition fingerprints, and cover subjects that do not map back to the concept premise. The command regenerates `melanies-game-content-audit.md` with taxonomy coverage, closest premise pairs, deterministic round-diversity metrics, and cover-motif coverage for reviewer inspection.
