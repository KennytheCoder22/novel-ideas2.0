Production order
api/3d-generate.ts receives the provider GLB. Infer returns those bytes directly.
Mirror calls processNormalSymmetry(input) with no request-supplied gate options.
The processor computes global eligibility, its frozen local LIMITED path, the
structural-continuity veto, and utility evidence from the input GLB. Only positive
normal utility reaches the private reconstruction function. All declines, missing
evidence and processing errors return the input Buffer unchanged. The production
module exposes no reconstruction function or approved-mask overload.

Frozen behavior
The global/local predicates were moved from the frozen JavaScript modules to
static imports. The Python/OpenCV structural and utility operations were ported
to Node with the same policy values, Float32 image arithmetic, median context,
3/7-pixel structural windows, surface-area weighting and six 512-pixel visibility
views. Float reductions may differ in their last rounding bits between runtimes;
no thresholds or decision rules are adjusted to compensate. Primary regions use
the existing Broad correspondence and largest >=0.75-confidence component. There
is no rescue, completion, synthesis, registration, propagation or tunable profile.

No frozen masks, processed model files, ground truth, intent labels or fixture
names are read in production. Correspondence and all evidence are computed from
the provider GLB. Test oracles live exclusively under tests/3d.

Mutation contract
On positive utility only, source color replaces authorized texels on an independent
material/texture. Original images and materials remain intact. Triangle material
runs retain original ordered triangle indices; vertex/normal/UV accessors and
scene hierarchy stay unchanged. No vertex construction, mirroring or movement.

Tests
npm run typecheck:3d-production
npm run test:3d-production

The API tests mock only the provider transport. They invoke the real request
handler, gates and writer, with no network call or Stability credit consumption.
They assert 1,161 exact clean-ground-truth repairs and zero other writes; all 15
adversarial clean fixtures remain byte-identical. They also test unsupported
models, invalid input, malicious approval/debug request fields, Infer pass-through,
original accessor/binary preservation and ordered triangle equivalence.
The fixture JSON is decoded geometry, run-length encoded clean pixels and sparse
paint edits from the frozen panel cases. It is not a processed GLB. The test builds
GLBs in memory and verifies the original fixture RGBA hashes before every case.
